# Qiben Ltd — Design System

## 1. Color Palette

### Primary Colors
- **Ink** `#102A43` — primary text, form fields, subtle backgrounds
- **Primary** `#146C66` — buttons, links, active states, accents
- **Accent** `#F0A85B` — highlights, badges, callouts, hover states

### Neutrals & Backgrounds
- **Paper** `#F7F8F6` — page background, cards, surfaces
- **Surface** `#FFFFFF` — modals, elevated cards, inputs
- **Muted** `#64748B` — secondary text, helper text, borders
- **Line** `#E2E8E5` — dividers, subtle borders, table lines
- **Tint** `#EFF3F0` — hover backgrounds, input focus, disabled states

### Dark Mode (prefers-color-scheme: dark)
- **Ink** `#E8EFED` — light text on dark backgrounds
- **Paper** `#101B1C` — dark page background
- **Surface** `#172526` — dark card backgrounds
- **Muted** `#A6B6B2` — dimmed text
- **Line** `#2A3A3A` — dark mode borders
- **Tint** `#1D2D2C` — dark mode hover
- **Primary** `#55B3A5` — lightened primary for dark bg
- **Accent** `#F0B66F` — lightened accent for dark bg
- **Shadow** `0 18px 54px #0004` — darker shadow for contrast
